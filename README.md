# Thronefall — Voice Packs

Downloadable per-language voice-over packs for the game **Thronefall** (Android).
The game downloads the pack for the player's language on demand; these files are not meant to be used on their own.

- One release per language pack version, asset `voice_<lang>.zip` (OGG Vorbis mono clips named by i18n key) + `voice_<lang>.json` (size, SHA-256).
- Voices generated with OmniVoice (k2-fsa). Model weights are licensed CC-BY-NC 4.0; these audio files are provided for non-commercial testing/preview only.
